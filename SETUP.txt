PHARMACY SIM — READY TO PLAY
============================

1. Open this folder in Unity Hub (2022.3 LTS or newer, including Unity 6).
2. First launch: automatic setup builds everything (~30–90 seconds).
3. Open scene: Assets/Scenes/PharmacyLab.unity
4. Press Play.

If scene is missing: menu → Pharmacy Sim → Setup Everything (Full Project)

If Unity upgrades the project/packages automatically, let it finish, reopen once, then run setup again.
